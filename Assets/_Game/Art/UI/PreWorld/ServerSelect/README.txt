Chibi Fantasy - Server Select Asset Pack

This ZIP contains brand-new generated standalone assets for the server select screen.
These are not crops from the screen mockup.

Files included:
- bg_server_select.png
- panel_server_list.png
- row_server_selected.png
- row_server_normal.png
- btn_back.png
- btn_enter.png
- status_online.png
- status_maintenance.png
- icon_compass.png
- title_select_server.png

Suggested Unity setup:
- Import as Sprite (2D and UI)
- Use Canvas Scaler -> Scale With Screen Size
- Reference Resolution -> 1920x1080
- Add TMP text separately for:
  * subtitle under title
  * column headers
  * server names
  * player counts
  * ping values
  * button labels if desired

Note:
Buttons and rows are provided as graphics. You can overlay TextMeshPro text on top.
