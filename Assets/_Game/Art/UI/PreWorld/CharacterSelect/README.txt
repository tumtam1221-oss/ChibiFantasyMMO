Chibi Fantasy Character Select - Standalone Generated Assets

Suggested Unity import:
- Texture Type: Sprite (2D and UI)
- Use alpha transparency where present
- Use panel_character_list_bg.png as the left-side panel background
- Place slot_character_selected.png / slot_character_normal.png / slot_create_character.png on top as separate UI items
